# TaskFlow — Real-Time Task & Project Management

A modern, high-performance real-time task and project management web application built with vanilla HTML5, CSS3, and modern JavaScript.

![TaskFlow Preview](https://img.shields.io/badge/Status-Active-brightgreen)
![License](https://img.shields.io/badge/License-MIT-blue.svg)

## 🌟 Key Features

- **Interactive Kanban Board**: Drag-and-drop tasks across customizable columns (Backlog, To Do, In Progress, Review, Done).
- **Multiple Views**: Switch seamlessly between Kanban Board, List View, Calendar, and Timeline/Gantt chart.
- **Real-Time Collaboration**: Live activity logs, notifications, and instant status updates.
- **Deep Analytics**: Visual charts for task completion rates, team productivity, priority distribution, and velocity tracking.
- **Rich Task Details**: Subtasks, attachments, priorities (Low, Medium, High, Urgent), tags, due dates, and assignee avatars.
- **Sleek UI / UX**: Modern dark & light mode styling, glassmorphism aesthetics, responsive layouts, and smooth micro-interactions.
- **Zero Build Step**: Pure HTML/CSS/JavaScript. No heavy node_modules or build dependencies required.

## 🚀 Getting Started

### Prerequisites
All you need is a modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

### Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/javoxirochilov20130707/real-time-task.git
   ```

2. **Open the project:**
   Simply double-click `index.html` or open it with your favorite browser:
   ```bash
   # Or serve with any static server:
   npx serve .
   # or Python:
   python -m http.server 8080
   ```

3. **Enjoy managing your tasks in real time!**
